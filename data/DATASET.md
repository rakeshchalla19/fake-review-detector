| Source column | Type | Meaning | Use |
|---|---|---|---|
| `category` | string | Product category, not a product identifier | Category reporting only |
| `rating` | numeric | Star rating from 1 to 5 | Excluded from classifier |
| `label` | string | `OR` original / `CG` computer generated | Target: OR=0, CG=1 |
| `text_` | string | English product review text | TF-IDF input |

The CSV contains 40,432 records with 20,216 of each label. The label CG means generated by GPT-2. OR is presumed human/authentic in the source; it does not mean independently fact-checked. This dataset does not supply platform-filter labels, verified human-deception labels, reviewer IDs or product IDs.

`python scripts/download_data.py` downloads and validates the exact source SHA-256. `python train.py` removes detected duplicate/conflicting groups and creates an experiment-specific derived dataset internally. Raw text is used as supplied for TF-IDF. The derived split manifest contains normalized-text SHA-256 identifiers instead of review text. Training changes are documented in README and metrics; the raw data is not bundled.

**User CSV is different:** `review` is required; `product` is optional. It contains no ground-truth label. `sample-reviews.csv` contains newly authored examples, not a training subset or a guaranteed prediction demonstration.
